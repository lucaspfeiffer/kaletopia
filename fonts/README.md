# Fonts

Self-hosted so the site makes no third-party requests. Declared in `src/layouts/Base.astro` so the URL can carry the site's base path.

- `UnifrakturMaguntia.woff2`: UnifrakturMaguntia by j. 'mach' wust and Gerrit Ansmann, SIL Open Font License 1.1. Used for the nameplate.
- `LibreFranklin.woff2`: Libre Franklin (variable weight, Latin subset) by Impallari Type, SIL Open Font License 1.1. Used for labels, navigation, and captions.

Headlines and body text use the reader's system serif (Georgia first).
